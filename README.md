## 🇺🇸 English

**Litematica Easy Place Variants** is a client-side Fabric mod for Minecraft that enhances Litematica's Easy Place functionality. It adds compatibility for equivalent block variants and guarantees perfect rotation synchronization.

### ✨ Features

- **Block Variant Compatibility**: Allows Litematica's Easy Place to substitute equivalent block types during placement. For example:
  - **Wood**: Replaces oak fences, trapdoors, stairs, gates, doors, or logs with cherry, spruce, mangroove, or any other wood type in your inventory.
  - **Stone**: Replaces stone walls, stairs, and slabs with diorite, andesite, sandstone, deepslate, or other variants.
- **Easy Place Fix (Client-Side Rotation)**: Fixes block rotation (stairs, chests, pistons, observers, fence gates, etc.) on vanilla and multiplayer servers. It intercepts placements and temporarily syncs the client-side placement simulation with faked server rotation, ensuring blocks are placed exactly as shown in the schematic without screen flicker!
- **State Equivalence Validation**: Blocks placed as variants are shown as correctly placed in Litematica's overlay as long as their properties (rotation, state) match the schematic.
- **Bilingual Interface & Settings Tab**: Adds a beautiful "Настройки Вариантов" (Variants Config) tab directly into Litematica's settings GUI (`M` -> Config Menu) with detailed Russian tooltips.

### 📥 Installation

1. Download and install [Fabric Loader](https://fabricmc.net/use/).
2. Download [Fabric API](https://modrinth.com/mod/fabric-api).
3. Download [Litematica](https://www.curseforge.com/minecraft/mc-mods/litematica) and [MaLiLib](https://www.curseforge.com/minecraft/mc-mods/malilib).
4. Place **Litematica Easy Place Variants** `.jar` file in your `mods` folder.

## 🇷🇺 Русский

**Litematica Easy Place Variants** - это клиентский Fabric-мод для Minecraft, расширяющий возможности режима Easy Place в Litematica. Он добавляет замену эквивалентных видов блоков и гарантирует идеальное сохранение их поворота при строительстве.

### ✨ Особенности

- **Поддержка вариантов блоков**: Easy Place может использовать эквивалентные блоки из вашего инвентаря вместо указанных в схеме:
  - **Дерево**: Заменяет дубовые заборы, люки, ступени, калитки, двери и брёвна на вишнёвые, еловые, багровые или любые другие виды древесины.
  - **Камень**: Заменяет каменные стены, ступени и плиты на диорит, андезит, песчаник, глубинный сланец и т.д.
- **Easy Place Fix (Умный Поворот Блоков)**: Решает проблему неправильного поворота блоков (ступеней, сундуков, поршней, наблюдателей, калиток) на ванильных и мультиплеерных серверах. Мод перехватывает установку и синхронизирует симуляцию взгляда на клиенте и сервере, обеспечивая идеальную ротацию без дёрганья камеры!
- **Проверка корректности установки**: Блоки, установленные как варианты (например, вишнёвая калитка вместо дубовой), будут считаться установленными верно, если их состояние (поворот, открытость) полностью совпадает со схемой.
- **Своя вкладка настроек**: Добавляет удобную вкладку «Настройки Вариантов» прямо в интерфейс настроек Litematica (`M` -> Config Menu) с полным описанием всех функций на русском языке.

### 📥 Установка

1. Скачайте и установите [Fabric Loader](https://fabricmc.net/use/).

3. Скачайте [Litematica](https://www.curseforge.com/minecraft/mc-mods/litematica) и [MaLiLib](https://www.curseforge.com/minecraft/mc-mods/malilib).
4. Поместите файл **Litematica Easy Place Variants** `.jar` в папку `mods`.
